# Artwork provenance

`public/worlds.png` was generated with the built-in image generation tool for this project. It is an original illustrative triptych, rather than captured gameplay. The app uses each third as a separate background through CSS positioning. The source image is retained locally in Codex's generated-images folder.

Final generation prompt:

> Create a cinematic landscape artwork triptych for the Loadstone desktop game modlist app. Image is very wide, approximately 3:1 aspect ratio, divided into THREE equal width vertical panels edge-to-edge, no gaps or borders, each third an independent coherent landscape illustration. Left third: richly detailed Mojave desert post-apocalyptic western road leading to a distant retro futuristic neon town at amber sunset, small lone traveler seen from behind, weathered electric poles, abandoned car, atmospheric dust and deep mountains. Middle third: cold Skyrim-inspired Nordic wilderness with dramatic snowy mountain ridges, ancient stone ruins and pine forests, small cloaked wanderer, pale blue mist, cinematic dark teal shadows. Right third: Fallout-inspired abandoned industrial American city reclaimed by green vegetation, distant domed building, rusted overpass, amber evening light, subdued olive greens. Polished realistic game environment concept art, dramatic beautiful lighting, strong silhouettes, dark lower portions appropriate for ivory text overlay. Every panel has its own horizon and focal point. NO TEXT, no labels, no logos, no letters, no UI. Original concept artwork.

The carved copper **L** in `public/brand/mark.svg` is the shared editable source for the desktop app, handbook and store compositions. `src/Logo.svelte` imports that vector. Run `pnpm assets:icon` to render the rounded basalt tile as `public/brand/icon.svg`, `public/icon.png` (512px) and `build/icon.ico` (16/24/32/48/64/128/256px). `scripts/create-icon.mjs` uses the locked Electron renderer in a hidden window, without network access or a separate Python/Pillow dependency. See the [brand system](../handbook/pages/brand.md) for palette, typography and review guidance.

## Steam branding kit

Run `pnpm assets:steam` after installing the locked development dependencies. `scripts/steam-artwork.mjs` renders eight SVG/PNG pairs and a PNG hash/dimension inventory to ignored `release/steam-artwork/`. It uses the pinned Electron renderer through Playwright, makes no network requests, and closes its hidden render window afterward. Re-running replaces only these generated output files.

The compositions use the shared mark, title-case Segoe UI lettering and quiet geometric planes on a basalt gradient. The Windows system font is rendered locally; no font files, game screenshots, third-party logos or AI landscape bitmap are embedded. The script and SVG mark are the editable sources; generated artwork is draft branding, not captured app behavior or evidence of a working modlist. The original generator and rendering source is covered by GPL-3.0-or-later. Bitmap artwork, packaged icons, screenshots, generated store media and videos are outside the source-code grant; their release and reuse terms remain to be finalized. The source license grants no trademark rights. See [COPYRIGHT](../COPYRIGHT) for scope.

Capsules contain only the title and mark. The library hero contains no text and the library logo has a transparent background. Sizes follow the [store](https://partner.steamgames.com/doc/store/assets/standard) and [library](https://partner.steamgames.com/doc/store/assets/libraryassets) specifications checked on 2026-10-01. Inspect small-capsule legibility and actual Steamworks crop/logo previews before submission. Client/community icons and real workflow screenshots remain separate deliverables.
