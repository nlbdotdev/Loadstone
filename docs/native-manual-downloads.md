# Guided manual Nexus downloads

Discover offers **Download Nexus files in my browser** for `.loadstone` recipes. Browser mode is the default unless the locally saved Nexus connection reports Premium. That saved status only selects the initial UI mode; uncached automatic downloads still require fresh Premium verification in the existing acquisition service. Manual selection itself needs no API key.

1. **Open Nexus file page** opens the declared game/mod/file page in the default browser. Sign in and use the website's manual download controls. Loadstone opens only that fixed Nexus URL, with no credential or signed download token; it does not automate the browser, scrape pages or bypass website restrictions.
2. **Choose and verify archive** selects the downloaded original file. Loadstone streams its bytes through SHA-256 and checks the declared length before accepting it. Large files show measured byte progress and **Cancel archive verification**. A mismatch, changed/redirected path, failed read or cancellation preserves the previous selection and all input files. Choose the exact declared version; a missing upstream file needs the creator's help.
3. **Use verified cache** explicitly checks that source's hash-named file in Loadstone's existing download cache. It performs the same full verification without a provider request, copying, publishing or deleting anything. Missing or corrupt cache files are not replaced. Manual files remain where the user selected them; this workflow does not populate the cache.
4. The guide tracks remaining Nexus archives and can show only archives still to select. In browser mode, installation review stays disabled until every Nexus source has a verified local selection. Clearing a selection returns that source to the pending count. Changing mode or a selection, including a cancelled picker or failed operation, invalidates the previous review.
5. Review and install through the existing builder. Selected archives are checked again during reconstruction, including archive structure and final outputs. “Verified when selected” records the completed selection check, not a promise that a file cannot subsequently change. Other original HTTPS sources may still be downloaded if selected in the reviewed plan.

The browser receives only a canonical `https://www.nexusmods.com/<game>/mods/<mod>?tab=files&file_id=<file>` URL constructed from validated recipe identifiers in the main process. The renderer sends a draft ID and source ID, never an arbitrary URL. Undeclared sources, non-Nexus sources, stale drafts and overlapping operations cannot open a browser. A browser-open failure is reported without exposing its raw error.

The same guide serves fresh builds, interrupted-build recovery, installed repair and separate-version updates. Selections, verification badges, manual mode and byte progress remain temporary; restart requires reselecting inputs. The source paths were already local guide data and remain excluded from build-history maps and diagnostic exports. No protocol association, browser profile, cookie, NXM key, signed URL, save or real installation is changed by this feature. Registered repairs retain their existing launch/recovery rules.

## Provider and acceptance boundaries

Nexus documents website-generated keys for non-Premium API download links. This manual-file flow leaves those website interactions with the user. Automatic Premium acquisition retains its existing request limits, credential isolation and original-source verification. Public API application registration and a real authorized account/download test remain release gates. Sources checked October 13, 2026: [Nexus download-link interface](https://github.com/Nexus-Mods/node-nexus-api/blob/master/src/Nexus.ts), [API acceptable-use policy](https://help.nexusmods.com/article/114-api-acceptable-use-policy).

Service tests cover exact bytes, cancellation, mid-read mutation, stale selections, redirected paths, source/URL injection, concurrent work, cache reuse and rechecking at installation. Actual Electron exercises the browser handoff through an intercepted opener, wrong-file rejection, visible hashing cancellation and successful local reconstruction with no Nexus account. These synthetic checks do not prove a real website/account interaction or a playable modlist. NXM protocol handling and automatic matching of a whole downloads folder remain separate work.
